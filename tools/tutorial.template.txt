【这个程序干什么】
  用电脑上的模拟器玩 FGO 时，把「登录时的账号数据」抓下来，
  存成 Chaldea 能直接导入的文件。你只需要进游戏到出现地球仪/公告页。

【你需要准备】
  1. Windows 10/11 电脑（不需要装 Python、不需要装任何抓包软件）
  2. 一个能开 root 的安卓模拟器（雷电 9 / MuMu 12 / 夜神都行，Android 7 以上）
     · 雷电 9：设置 → 其他设置 → root 权限 → 打开 → 重启模拟器
     · MuMu 12：设置 → 其他 → 开启 root
  3. 模拟器里装好 FGO
     · 华为渠道服：还要装 HMS Core（华为移动服务）并登录华为账号
  4. 模拟器重启过的话，每次抓之前重跑本程序（证书是临时挂的）

【三步操作】
  第 1 步  打开模拟器（一个或多个都行，一个模拟器一个服最省事）
  第 2 步  双击 FGOCapture.exe，等它打印出识别结果
  第 3 步  依次进游戏，登录到出现地球仪/公告页
           · 窗口里出现「★导入文件已生成」= 这个服成功了
           · 全部成功后会自动停止（也可以随时按 Ctrl+C）

【结果在哪】
  程序旁边会生成：
    out\<日期时间>\导入文件\<服名>_toplogin.json
  这就是要导入 Chaldea 的文件；其它中间文件程序会自动删掉，
  只留导入文件（想全留就加参数 --keep-all）。

【导入 Chaldea】
  打开 Chaldea → 导入数据 / 抓包导入 → 选对应区服 → 选上面那个 json。
  · 文件名里带「简中服-安卓区 / 简中服-iOS区 / 简中服-渠道服 / 繁中服」的，就选对应区服；
  · 原样导入，不要用记事本打开另存，不要转码。

【怎么确认文件没被人改过】
  · 双击前先跑：  FGOCapture.exe --verify
    会打印本文件的 SHA-256、内置数据自校验结果、签名证书指纹。
    自校验必须是「通过」；签名指纹必须是：
      {{THUMB}}
  · 本文件的 SHA-256 应为：
      {{SHA256}}
    对不上说明被替换过，别运行，找发给你的人重新要。
  · Windows 里也能看：右键 exe → 属性 → 数字签名。
    （自签名证书会显示「未知发布者」，正常；关键是指纹对不对）

【常见问题】
  · 一直「尚未抓到登录」：游戏还没走到登录，等它加载完；或游戏还没更新完。
  · errors.log 里刷 TLS 失败：模拟器 root 没开，或游戏进程是抓包前就在跑的
    （程序会自动结束它，你重新打开游戏即可）。
  · 华为服登录报 -104：先关掉 Drony 等其它代理/加速器再试。
  · 忘了 Ctrl+C 导致游戏连不上网：运行  FGOCapture.exe --clean  还原。
  · 换个模拟器/实例：不用改配置，程序自动找；找不到用 --adb 指定模拟器自带 adb。

【参数（一般用不到）】
  --verify          只看校验信息，不抓包
  --tutorial        显示本文
  --list            只列出模拟器识别结果
  --dry-run         只打印抓包计划
  --only jp         只抓指定服（jp / bilibili / huawei / xiaomi …）
  --duration 120    抓 120 秒后自动停
  --keep-all        保留全部中间文件
  --clean           还原代理、卸载证书

【注意】
  · 只抓你自己设备、你自己账号的数据；生成的 json 等于账号数据，别外传。
  · 抓包属于灰色地带（官方未明确许可），但本程序只读不写、不改客户端、
    不自动化，正常使用风险很低；介意的话别用。
